Habits

Connect Google Sheets so your data is permanent.

Step 1 — Create a Google Sheet

Go to sheets.google.com and create a blank spreadsheet. Name it anything, e.g. "Habits".

Step 2 — Open Apps Script

In your sheet, click Extensions → Apps Script. Delete the existing code, paste the launcher below, then click Save (Ctrl+S / Cmd+S). This is the only code you'll ever need to paste — updates happen automatically.

Step 3 — Deploy as Web App

Click Deploy → New deployment → Web app.
Set Execute as: Me and Who has access: Anyone.
Copy the Web App URL and paste it below.

Step 4 — (Optional) Enable AI Insights

In Apps Script: gear icon → Script Properties → Add property.
Add CLAUDE_API_KEY = your Anthropic key (from console.anthropic.com → API Keys). Your key stays secure server-side.
