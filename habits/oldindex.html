Connect Google Sheets so your data is permanent and never lost.

Step 1 — Create a Google Sheet

Go to sheets.google.com and create a new blank spreadsheet. Name it anything, e.g. "Habits Tracker".

Step 2 — Open Apps Script

Inside your sheet, click Extensions → Apps Script. Delete any existing code and paste this:

Step 3 — Add Script Properties

In Apps Script, click the gear icon (Project Settings) → Script Properties → Add property.

Required: HABITS_TOKEN = habits2026

Optional (AI insights): CLAUDE_API_KEY = your Anthropic key

Find your Claude key at console.anthropic.com → API Keys.

Step 4 — Deploy as Web App

Click Deploy → New deployment → Web app.
Set Execute as: Me and Who has access: Anyone.
Click Deploy, authorize when prompted, then copy the Web app URL.
